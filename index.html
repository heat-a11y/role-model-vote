Before you start
  1. Follow the README to create the Firebase project and paste the keys into js/firebase-config.js.
  2. On the master dashboard, set the question and the candidate names, and add your classes with roll sizes.
  3. Press Open voting.
  4. On each class laptop, open kiosk.html&class=3A (your class) and leave it running.
